# VoiceSecure
🎙️ VoiceSecure – AI Deepfake Voice Detector
Demo Link: https://pallavixd.github.io/VoiceSecure/

VoiceSecure is a frontend-based AI Deepfake Voice Detection demo that simulates the process of identifying whether an uploaded audio file is human-generated or AI-generated.
It features a futuristic UI, authentication simulation, audio upload, animated analysis flow, and confidence-based results all implemented in a single index.html file.

⚠️ Note: This project is a UI/UX and logic simulation. No real machine learning model is used. Detection results are randomly generated to demonstrate workflow.

🚀 Features

🔐 User Authentication (Simulated)

Login & Signup using localStorage

Session handling via sessionStorage

🎧 Audio Upload

Supports MP3, WAV, FLAC

Drag & drop or click-to-upload

🧠 AI Analysis Simulation

Animated waveform & scanline effects

Fake ML pipeline steps (MFCC, CNN, spectrogram)

📊 Detection Results

Human Voice vs AI Generated

Confidence bar & animated score

🎨 Modern Cyber UI

Glassmorphism design

TailwindCSS

Font Awesome icons

Neon / futuristic theme

🛠️ Tech Stack

HTML5

Tailwind CSS (CDN)

Vanilla JavaScript

Font Awesome

Google Fonts

LocalStorage & SessionStorage

No backend, server, or external API is required.

▶️ How to Run

Download or clone the repository

Open index.html in any modern browser (Chrome, Edge, Firefox)

Register a new user

Login

Upload an audio file

Click Analyze Frequency

View detection results

No installation or build steps required.

🔍 How It Works (Simulation)

Audio files are not analyzed

Detection outcome is randomly generated:

50% chance Human Voice

50% chance AI Generated

Confidence score is randomized between 80–99%

All “AI processing” steps are visual and educational only

🔐 Security Notes

Passwords are stored in plain text (for demo purposes only)

No encryption or hashing is implemented

Do NOT use this code in production environments
